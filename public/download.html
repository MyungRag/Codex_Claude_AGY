ZIP 파일 직접 열기

실행하는 순서

  1. 받은 ZIP 파일을 오른쪽 클릭하고 모두 압축 풀기를 선택하세요.
  2. Node.js가 없다면 공식 사이트에서 LTS 버전을 설치하세요.
  3. 압축을 푼 agent-desk 폴더에서 start-windows.cmd를 더블클릭하세요.
  4. 브라우저가 자동으로 열리지 않으면 http://127.0.0.1:4173에 접속하세요. 실행 중에는 명령창을 열어 두세요.

개발·검토 시작하기

프로젝트 상단의 개발·검토를 여세요. 통합안 등 다섯 방식의 흐름도와 장단점을 보고, 전체 총괄·Builder·Auditor·Challenger를 지정합니다. 기획과 업무 분담을 저장한 뒤 검사 명령과 프로그램 실행 방법을 설정하고 시작하세요. 개발에는 Git과 사용할 AI CLI가 필요합니다.

원본 폴더와 별도의 작업본에서 구현·검사합니다. 실패·미개발 부분을 다른 방식으로 다시 처리하며, 이전에 실행을 확인한 버전은 보존합니다. 시작 확인과 검토 통과는 각각 표시하고 남은 한계도 결과물에 포함합니다.

기획과 AI 요청

AI 요청은 기본 무제한 대기를 지원하고, 요청 번호를 받기 전에도 취소할 수 있습니다. 중요한 미답변 질문을 남긴 채 기획을 확정하며, 확정 메모를 보존하면서 이전 탭으로 이동할 수 있습니다.

  1. 질문·결정에서 답변 필요 / 확인 필요 / 결정 완료를 항목별로 관리합니다. AI 세 개가 검토한 질문을 미리 보고 반영하며, 같은 질문의 AI 의견은 함께 보관합니다.
  2. 노드 정리를 적용하면 관련 질문도 함께 정리됩니다. 답변한 노드가 바뀌면 답변을 보존하고 재확인을 요청합니다. 되돌리기로 함께 복원할 수 있습니다.
  3. 기획 확정 · 업무 분담에서 미결정·충돌·완료 기준을 확인하고 버전으로 확정합니다. 담당 AI·선행 작업·지시를 편집하고 분담서를 내려받을 수 있습니다. 작업 실행은 시작하지 않습니다.

기존 실행기 명령창을 닫고 새 ZIP의 실행기를 시작하세요. 웹 새로고침만으로는 PC 실행기가 업데이트되지 않습니다. AI 연결에서 PC 실행기 v0.9.3을 확인하세요.

회사 PC에서 이어하기

  1. 지금 사용 중인 화면에서 프로젝트·기획 백업 또는 전체 프로젝트 백업으로 JSON을 저장하세요.
  2. 회사 PC에서 이 ZIP을 내려받아 실행하고, 프로젝트 목록의 가져오기로 JSON을 불러오세요.
  3. 현재 PC 폴더를 회사 폴더로 다시 선택하고 각 CLI 로그인·AI 연결을 확인하세요.
  4. 집으로 돌아올 때도 회사에서 최신 JSON을 백업하세요. 가져오기는 기존 프로젝트를 보존하고 새 복사본을 추가합니다.

GitHub는 프로그램 코드를 옮기는 데 사용합니다. push는 올리기, clone은 처음 받기, pull은 변경분 받기입니다. 현재 버전의 브라우저 기획 데이터는 Git으로 자동 동기화되지 않으므로 JSON 백업이 필요합니다. 실제 개발 기록과 결과물은 PC 사용자 홈의 .agent-desk/development 폴더에 별도로 저장됩니다.

세 AI 연결하기

  1. 공식 CLI를 설치하고 로그인하세요: Codex · Claude Code · Antigravity CLI. 데스크톱 앱 로그인과 별도일 수 있습니다.
  2. 실행한 화면 오른쪽 위 AI 연결에서 설치를 확인하고 각 응답 테스트를 누르세요.
  3. 기획 보드 → AI 기획 요청에서 에이전트를 선택하고 요청하세요. 응답을 확인한 뒤 그래프에 반영할 수 있습니다.

웹 대시보드에서도 사용하려면 로컬 화면의 AI 연결 → 웹 연결 코드 복사 후, 웹의 AI 연결 화면에 주소와 코드를 입력하세요.

기획 보드 둘러보기

프로젝트를 열고 기획 보드 → KAF 시연으로 기능 둘러보기를 선택하세요.
연결선의 +로 노드를 추가하고 수정한 뒤 새로고침해 보세요.

기존 실행판을 사용 중이면 명령창을 닫고 새 패키지로 다시 실행하세요. 같은 브라우저와 주소를 사용하면 기존 프로젝트 정보가 유지됩니다.

실제 응답 테스트와 기획 요청에는 각 서비스 계정의 사용량이 적용됩니다. 설치·로그인·지원 CLI 버전 확인이 필요하며 자세한 안내는 ZIP 안의 README에 있습니다.
