# v0.13.0 검증 기록

2026-11-14 · Linux / Node.js 24 / 실제 Chromium

## 변경

- AI의 개별 응답 종료와 프로그램 결과를 분리했습니다. 프로젝트 상단에서 실행 초안 확보, 실행 실패, 취소, 진행 중 상태와 기능별 코드·연결·통합 검증·미개발 수를 표시합니다. 실행·다운로드 화면으로 바로 이동합니다.
- 생성한 `agent-desk.launch.json`으로 정적 진입 파일 또는 준비·빌드·서버 명령을 적용합니다. 실제 시작 오류와 설정을 다음 초안 복구 요청에 전달합니다. TypeScript/JSX를 정적 페이지에서 바로 불러오는 오류를 설명합니다. 하위 폴더의 시작 파일과 상대 경로도 연결합니다.
- 시작 가능한 버전이 없더라도 생성 소스와 검사·실패 기록을 인증된 API로 ZIP 다운로드할 수 있습니다. 실행 완료 패키지로 표시하지 않으며, 실패를 수용해 통과시키지 않습니다. 이전 실행 버전도 유지합니다.
- 개발·검토 횟수 소진에 따른 조합 교체와, AI 사용량·인증·모델·연결·응답 시간 초과에 따른 인계를 별도 설정으로 구분합니다. 인계는 현재 요청·단계의 저장 코드와 검사 자료를 사용합니다. 같은 요청에서 각 AI는 한 번씩, 최대 세 AI까지 시도합니다. 사용할 수 없는 AI는 해당 개발 시도에서 제외하고 다음 사용자 실행에서 다시 평가합니다.
- 인계 시 사용 가능한 주 AI를 우선하되 바쁜 주 AI 때문에 다른 가용 AI를 기다리게 하지 않습니다. 검토는 다른 작성자를 먼저 사용하고 마지막으로 자체 검토합니다. 사용자 취소, 작업별 보류, 전체 작업 시간 한도 후에는 자동 재시작하지 않습니다. 기존 수정·검토 한도도 유지합니다.
- 같은 AI 요청은 순차, 독립 작업과 다른 AI는 병렬이라는 기존 실행 제약을 유지합니다. Challenger는 필요한 실패·쟁점 분석에 사용하며 성공한 작업에 무조건 추가 분석을 요청하지 않습니다.
- 기획 보드와 작업 지도는 목표→하위→하위의 하위까지 기본 표시합니다. 계획의 깊이를 강제하는 변경이 아닙니다. 펼침 상태, 선택과 스크롤을 상태 갱신 시 보존합니다. 기획 보드의 확대와 펼침 상태는 화면을 떠났다가 돌아와도 복원합니다.
- 노드와 연결선, AI 카드에 실제 실행 중인 AI의 색상과 역할을 표시합니다. 연결 확인이 필요하면 실행 중으로 단정하지 않습니다. 동작 감소 설정을 존중하고 자동으로 현재 작업에 스크롤하지 않습니다.
- AI 실행 확인은 커진 상단 탭 하나로 접근합니다. 내부의 실시간/사용량 세부 탭은 유지하고 개발 화면의 중복 탭은 제거했습니다.
- 개발 시도들의 누적 경과, 병렬 중복을 뺀 AI 활동 경과, AI별 처리 시간 합계와 현재 요청 시간을 구분합니다. AI·역할별 입력/출력/총 토큰을 보고된 범위에서 집계하고 완료된 기획·개발 호출 기록을 서버에 저장합니다. 기존 실행기의 이미 사라진 기획 호출은 복원할 수 없습니다.

## 검증

- 전체 자동 테스트: **294개 통과**. 코드 변경 후 관련 회귀 검사와 문법 검사를 추가 수행했습니다.
- 실제 자식 프로세스의 세 CLI 응답 형식으로 빌드, 감사, 사용량 한도 오류, 주 AI 인계와 호출 기록 저장을 확인했습니다. 인계 테스트에는 중간 감사 실패, 제3 AI 우선, 자체 검토 최종 대체, 바쁜 주 AI 회피, 타임아웃, 취소, 모든 제공자 실패와 인계 비활성화가 포함됩니다.
- 실제 격리 파일/Git/HTTP에서 누락된 시작 파일을 복구한 실행 정의를 적용했습니다. 준비 명령은 실행 복사본에서만 파일을 만들고 고정 소스를 바꾸지 않는지 검사했습니다. 끝내 시작에 실패한 경우에도 소스·실패 기록 ZIP을 확인했습니다.
- `node verification/v0.13.0-browser.mjs`: 실제 Chromium에서 독립 기획 3개→주 AI 통합, 기획 반영, 병렬 개발, 노드 진행/완료, 실행 미리보기, 다운로드, 실패한 새 초안과 이전 실행 버전 보존을 확인했습니다. 계산기 실행 검사 8개, 브라우저 콘솔 예외 0개. 응답은 결정적 CLI fixture입니다.
- `node verification/v0.13.0-panels.mjs`: 24개 작업의 화면 검증 예시에서 실제 Chromium 스크롤 위치·선택 유지, 세 AI의 개발/검토/Challenger 색상, 누적 시간·사용량, 390px 모바일 넘침 없음을 확인했습니다. 이 화면의 KAF 상태는 UI 검증용 데이터이며 사용자의 KAF 실행 결과가 아닙니다.

## 범위와 한계

실제 Windows에서 사용자 계정으로 Codex·Claude·Antigravity를 호출하거나 사용자의 KAF 소스를 실행한 결과는 아닙니다. 자동 복구는 최대 3회이며 외부 서비스·계정·자료·도구가 없으면 실행 초안을 확보하지 못할 수 있습니다. 그 경우도 소스와 실제 실패 기록을 전달하고 미완성을 명확히 표시합니다. HTTP 시작 성공은 모든 기능의 동작 확인을 뜻하지 않습니다. 통합 연결과 기능 검증은 별도 근거가 있는 경우에만 표시합니다.
