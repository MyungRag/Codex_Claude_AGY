# v0.9.0 검증 기록

환경: Node.js 24, Linux, 실제 Chromium. AI 호출은 공식 CLI 응답 형식을 내보내는 테스트용 프로세스로 대체했으며 실제 공급자 계정은 사용하지 않았습니다. Windows용 ZIP의 내용은 검증하지만 Windows 실기기에서 실행한 기록은 아닙니다.

2026-11-13 최종 결과: 전체 자동 테스트 **203개 통과, 실패 0개**, 애플리케이션·실행기 모듈 구문 검사와 `git diff --check` 통과.

## 질문·노드 통합

- Codex·Claude·AGY 독립 검토 후 선택한 주 AI를 추가 호출: 총 4회.
- 추가 요구는 독립 응답을 재사용하고 주 AI만 다시 호출.
- 의미가 다른 문장으로 표현된 같은 질문의 통합, 출처 보존, 반복 적용 시 기존 질문·답변 유지.
- 선택지 첫 항목이 RAD여도 명시적 추천값 DEG 채택, 사용자 선택·직접 답변·새 대화 우선.
- 과거 대화로 새 수동 답변을 덮어쓰지 않음. 외부 사실과 사용자 보류는 자동 확정하지 않음.
- 출처 누락·노드 범위 오류·서로 다른 저장 답변 병합은 변경 전 거부.
- 다단계 계층·기존 작업 세분화·질문 ID 보존·되돌리기.
- 저장 실패 시 응답/입력 유지, 재개 시 불필요한 AI 호출 없음, 저장 성공 시 임시 상태 삭제.
- 이전 버전의 미반영 응답을 다시 생성하지 않고 주 AI 통합으로 전환.

Chromium UI 실행에서도 입력 직후 **한 번의 실제 클릭**으로 반영·창 닫힘을 확인했습니다. 새로고침 후 다시 질문 검토해도 질문 1개와 사용자 답변이 유지됐고, 주 AI를 Claude로 지정한 3개 AI 노드 정리 후에도 답변이 보존됐습니다. 모바일 가로 넘침과 페이지 JavaScript 오류는 없었습니다.

## 계산기 초안과 실제 실행 검사

`tests/draft-through.test.mjs`는 미답변 각도 질문에 DEG 기본값 채택 → 기획 확정 → 업무 분담 → 계산 엔진 노드 → 화면 노드 → 실행 버전 보관까지 실행합니다. 각 AI 역할은 테스트용 CLI 프로세스를 사용하고 실제 파일 적용·Git 커밋·검사·브라우저 실행은 호스트에서 수행합니다.

- Node.js에서 계산 우선순위·괄호·삼각함수·잘못된 입력 등을 검사.
- 실제 Chromium에서 연산·괄호·DEG/RAD·오류 입력의 화면 결과를 검사.
- 코어는 정상이고 UI 결과만 999로 고장 낸 경우 화면 검사가 실제 실패.
- 최종 코드 SHA와 검사·독립 검토 기록이 일치하고, 최종 재검토 결과가 실행 버전에도 반영됨.
- ZIP에 기준 기획·선택지·AI 가정·노드별 파일/검사 근거 포함. 원본 작업 폴더 보존.
- 미결정으로 막혔던 선행 작업은 새 기본값을 받은 후 재검토를 통과해야 후속 작업이 실행됨. 특정 노드만 선택한 재실행 범위도 보존.
