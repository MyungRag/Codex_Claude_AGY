# v0.9.1 자동 통합 흐름 검증

노드 정리·질문 검토의 시작 전 주 AI 선택과 중간 조작 없는 자동 진행을 검증합니다. 이전 버전의 새 검토도 자동 통합했으나 대기 중 수동 버튼이 혼동을 주었고, 새로고침 후 복구 경로에서는 통합이 자동으로 이어지지 않았습니다.

2026-11-13: 전체 자동 테스트 **206개 통과, 실패 0개**, 애플리케이션·실행기 구문 검사와 `git diff --check` 통과.

`tests/lead-review-ui.test.mjs`에 다음 회귀 검증을 추가했습니다.

- 노드 정리와 질문 검토 모두 시작 전에 선택한 주 AI를 사용.
- 독립 검토가 모두 끝나기 전에는 주 AI를 호출하지 않음. 모두 끝난 뒤 추가 클릭 없이 정확히 한 번 호출.
- 진행 중 수동 통합 버튼 대신 단계와 미리 선택한 주 AI 표시.
- 이전 버전의 진행 중 응답을 복원하고 실행기 기능 정보를 확인한 뒤 자동 통합.
- 완료된 통합을 다시 호출하지 않으며, 취소한 작업은 재개하지 않음.
- 최종 기획 반영은 사용자 클릭을 기다림.

실제 Chromium과 테스트용 CLI 프로세스로 노드 정리 도중 새로고침한 뒤 재진입하여 **독립 검토 3회 + 선택했던 AGY 통합 1회**를 확인했습니다. 질문 검토도 **독립 검토 3회 + 선택했던 Claude 통합 1회**였으며, 두 경우 모두 수동 통합 버튼 클릭은 0회입니다. 페이지 JavaScript 오류는 없었습니다. 실제 공급자 계정이나 Windows 실기기로 수행한 검증은 아닙니다.
