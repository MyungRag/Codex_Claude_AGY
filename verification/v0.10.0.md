## 변경 범위

- 새로 추가되거나 구현 내용이 바뀐 노드만 질문 검토. 기존 답변 보존과 이전 검토 범위의 이어가기.
- 실제 AI 호출 메타데이터를 보여주는 **AI 실행 확인**: **실시간 역할·작업**, **호출·사용량 기록** 두 탭. 프로젝트 전체 실행 표시와 기획 검토에서 모니터로 이동.
- 재귀적인 포함 계층과 선행 관계를 구분하는 기획도·작업 진행. 마지막 초안 통합 작업도 기획도에서 확인.
- 최대 3개 독립 작업 실행, 공급자별 대기열, 격리된 코드 변경의 순차 반영, 공유 파일 충돌 시 최신 코드로 1회 재시도.
- 전체 검증과 후속 작업의 필수 결과물 준비를 구분. 작성자 자체 검토 허용과 독립 검토 호출 실패 시 자체 검토 시도.
- 환경 실패와 실제 검사 실패 구분. 남은 기능을 격리하는 초안 통합 시도, 기존 실행 버전 보존.
- 실제 프로그램 실행·미리보기·중지. 진행 정보 갱신 시 미리보기 프레임 유지.

## 확인 범위와 적용

Windows ZIP에는 현재 소스·실행기·Windows 시작 파일을 넣습니다. ZIP CRC와 버전, 새 모듈 포함 여부를 확인합니다. Windows 실기기 실행, 실제 Codex·Claude·Antigravity 계정 응답 품질·토큰 보고는 이번 검증에 포함하지 않습니다. 미검증을 통과로 표시하지 않으며 실제 핵심 검사 실패는 새 실행 버전을 차단합니다. 기능 구현 성공이나 AI 응답 품질을 보장하는 변경은 아닙니다.

진행 중 요청을 완료하거나 취소한 뒤 기존 명령창을 `Ctrl+C`로 종료하고 새 ZIP을 별도 폴더에서 실행합니다. 기존 브라우저의 같은 주소·탭에서 `Ctrl+Shift+R`을 누릅니다. 프로젝트·브라우저 데이터·사용자 홈의 `.agent-desk` 폴더를 삭제할 필요가 없습니다. 앱 폴더를 바꿔도 같은 PC의 저장된 실행 이력과 결과물은 유지합니다.
